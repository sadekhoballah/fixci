هذا دليل إرشادي ممتاز ومصمم بعناية فائقة من قِبل Claude!

الجميل في هذا الدليل أنه **أوتوماتيكي تقريباً**؛ حيث سيتكفل سكربت `00-provision.sh` بتثبيت كافة البرامج (Node, Docker, Flutter, PostgreSQL...)، وما عليك أنت سوى تنفيذ الخطوات التوجيهية وتمرير الملفات السرية التي قمت بضغطها وحفظها سابقاً.

إليك **شرح شامل ومبسط خطوة بخطوة** لما ستقوم به عندما تشتري سيرفر Ubuntu 24.04 VPS الجديد:

---

## 📌 الخطوة 1: الاتصال بالسيرفر الجديد (SSH)

افتح الـ Terminal في حاسوبك واتصل بالسيرفر عبر عنوان الـ IP الخاص به:

```bash
ssh <اسم-المستخدم>@<ip-السيرفر>

```

> 💡 **ملاحظة:** إذا زوّدتك شركة الاستضافة بحساب `root` فقط، قم بإنشاء مستخدم عادي ومنحه صلاحيات `sudo` (لا تقم بتشغيل كل شيء بـ root):
> ```bash
> adduser samoce
> usermod -aG sudo samoce
> su - samoce
>
> ```
>
>

---

## 📌 الخطوة 2: سحب مشروع `fixci` لأول مرة (Bootstrap)

بما أن المستودع خاص (Private Repository) ومفاتيح السيرفر لم تُنشأ بعد، ستستخدم مفتاح SSH الخاص بحاسوبك لتجاوز هذه الخطوة لأول مرة فقط.

1. **من حاسوبك الشخصي (ليس السيرفر):**
```bash
ssh -A samoce@<ip-السيرفر>

```


*(خيار `-A` يقوم بتمرير مفتاحك الخاص مؤقتاً للتأكيد على GitHub دون نسخه داخل السيرفر).*
2. **داخل السيرفر:**
```bash
cd ~
git clone git@github.com:sadekhoballah/fixci.git

```



---

## 📌 الخطوة 3: نقل ملف الأسرار المضغوط إلى السيرفر

الآن ستنقل ملف `fixpro-secrets-20260730.zip` الذي أنشأته سابقاً إلى السيرفر الجديد وتفك ضغطه مؤقتاً:

1. **من حاسوبك الشخصي (أو المكان الموجود فيه الملف):**
```bash
scp fixpro-secrets-*.zip samoce@<ip-السيرفر>:~/

```


2. **داخل السيرفر:**
```bash
sudo apt install -y unzip
unzip -e fixpro-secrets-*.zip -d ~/fixpro-secrets-tmp

```


*(سيسألك النظام عن كلمة السر التي اخترتها لتشفير الـ zip أثناء الفك).*

---

## 📌 الخطوة 4: تشغيل سكربت التثبيت الآلي (Provisioning)

ادخل لمجلد الـ infra وابدأ تشغيل السكربت الرئيسي:

```bash
cd ~/fixci/infra
./00-provision.sh

```

### ⚠️ توقف مؤقت لتفعيل مفاتيح GitHub:

سيتوقف السكربت عند المرحلة 3 ويطبع لك مفتاحاً عاماً (Public Key).

* انسخ هذا المفتاح واذهب لمواقع المستودعات الثلاثة على GitHub (`fixci`, `fix-pro-web`, `fix-pro-dashboard`).
* في إعدادات كل مستودع (`Settings` -> `Deploy keys`)، أضف المفتاح واجعل صلاحيته القراءة فقط (Read-only).
* اعد إلى الـ Terminal واضغط **Enter**.

---

## 📌 الخطوة 5: التوقف الأول للأسرار (Secrets Pause 1)

سيتوقف السكربت ويطلب منك وضع ملفات الـ `.env` ومفتاح Firebase في أماكنها:

1. **انسخ الملفات من المجلد المؤقت:**
```bash
cp ~/fixpro-secrets-tmp/backend.env ~/fixci/backend/.env
cp ~/fixpro-secrets-tmp/fixci-ff69c-firebase-adminsdk-fbsvc-7ed69dc256.json ~/fixci/backend/
cp ~/fixpro-secrets-tmp/dashboard.env ~/fix-pro-dashboard/.env

```


2. **عدّل ملف `backend/.env` للتأكد من إعدادات الإنتاج:**
افتـح الملف بـ `nano ~/fixci/backend/.env`:
* تأكد من أن `NODE_ENV=production`
* تأكد من أن `ALLOWED_ORIGINS=[https://fix-pro.app](https://fix-pro.app)`
* تأكد من أن `ALLOW_DEV_AUTH_BYPASS=` (فارغ تماماً وليس true).


3. **توليد مفاتيح تشفير جيدة للإنتاج (الرموز السرية):**
نفّذ هذا الأمر مرتين في الـ Terminal لتوليد نصين مشفرين:
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"

```


* ضع النص الأول في خيار `ADMIN_JWT_SECRET` داخل `.env`
* ضع النص الثاني في خيار `WAVE_WEBHOOK_SECRET` داخل `.env`


4. اعد للسكربت واضغط **Enter**.

> ⏳ **ملاحظة:** في هذه الأثناء سيقوم السكربت ببناء الـ Backend والـ Web ولوحة التحكم (Flutter Web). هذه الخطوة قد تستغرق من **3 إلى 7 دقائق** لبناء Flutter.

---

## 📌 الخطوة 6: التوقف الثاني للأسرار (Cloudflare Tunnel)

سيتوقف السكربت للمرة الثانية ليطلب منك ربط نفق Cloudflare:

1. **انسخ ملفات النفق:**
```bash
sudo mkdir -p /etc/cloudflared
sudo cp ~/fixpro-secrets-tmp/b4d53db2-efc0-4ae1-a694-9ba925888424.json /etc/cloudflared/
sudo cp ~/fixpro-secrets-tmp/config.yml /etc/cloudflared/

```


2. اعد للسكربت واضغط **Enter**. سيقوم السكربت بتشغيل أداة `cloudflared` وتأمين حماية الملفات وتفعيل النفق ليصبح موقعك حيّاً أونلاين عبر الدومين الرسمي `fix-pro.app`!

---

## 📌 الخطوة 7: تنظيف الأسرار المؤقتة

أمسح المجلد المؤقت وملف الـ Zip من السيرفر لزيادة الأمان:

```bash
rm -rf ~/fixpro-secrets-tmp ~/fixpro-secrets-*.zip

```

---

## 📌 الخطوة 8: التحقق وإيقاف النفق القديم

1. **تحقق من تشغيل السيرفر بالكامل من داخل الـ VPS:**
```bash
./70-verify.sh

```


2. **تحقق من حاسوبك الشخصي (Laptop):**
افتح الـ Terminal في حاسوبك واكتب:
```bash
curl -I https://fix-pro.app/

```


إذا ظهرت لك الاستجابة برقم `200 OK` فهذا يعني أن الدومين أصبح يعمل رسمياً من السيرفر الجديد (VPS).
3. **إيقاف النفق القديم:**
اذهب إلى حاسوبك المحلي القديم واتبع التعليمات الموجودة في ملف `fixci/infra/teardown-old-tunnel.md` لإيقاف خدمة `cloudflared` القديمة حتى لا تعارض السيرفر الجديد.
